# Telugu States Realestate — Premium Multi-Page React Website

## Stack
- React + Vite
- React Router DOM
- Framer Motion
- Lucide React
- Montserrat

## Pages
- `/` — Home
- `/properties` — Property collection with filters/search
- `/locations` — Locations
- `/about` — Brand story
- `/contact` — Enquiry page

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
The supplied Telugu States Realestate logo is used as the primary brand asset. Property cards and claims are intentionally presentation-ready placeholders where verified live inventory/project documentation should be inserted before launch.
